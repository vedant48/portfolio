## ⚡ Tech Stack & Architecture

- **Framework**: Next.js 16 (Turbopack, App Router, Static Site Generation)
- **Language**: Strict TypeScript
- **Styling**: Vanilla CSS Variables & Tailwind CSS tokens (Kurosawa design system)
- **Icons**: Lucide React
- **Aesthetics**: High-contrast dark/light mode, bespoke outlined typography, micro-interactions, responsive grid hierarchy

---

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
